📖 项目资产台 · 使用教程

🚀 快速开始

  1. 新建项目：点击工具栏 📋 粘贴建项目，粘贴大禹/排期文本，自动识别项目名和关卡并在 D 盘创建文件夹
  2. 扫描已有项目：点击 🧩 扫描D盘项目，自动发现 D 盘所有 XX-项目名（游戏项目） 目录并同步到工作台
  3. 手动添加：在底部「新增项目」输入框输入项目名，点击添加

🎬 动画工作流

  1. 选择顶部 🎬 动画 标签，进入动画资产管理模式
  2. 展开项目 → 展开关卡 → 查看每个素材槽位（Spine / GIF / MP4 等）
  3. 槽位状态：todo（待制作）→ partial（制作中）→ done（已完成）
  4. 点击状态徽标可切换；每次切换自动记录事件日志用于效率统计

✨ AI 截图识别

  1. 在页面任意处按 Ctrl+V 粘贴截图，或点击拖拽区上传图片
  2. AI 自动识别截图中的修改需求，提取项目名、关卡、修改内容
  3. 识别完成后点击 📌 存入备忘录，自动归入待处理列表

📌 待处理备忘

  • 支持 P0 ~ P3 四级优先级，手动输入或从 AI 识别结果存入
  • 可直接粘贴领导的整段需求，AI 会智能拆分为多条备忘
  • 备忘可一键归档到对应项目的关卡槽位

🧠 资产扫描

  • 点击 🧠 扫描资产，自动检测当前项目关卡文件夹中的 Spine 三件套（.spine / .atlas / .json）
  • 识别到的资产自动填充对应槽位，并根据文件时间判断产物状态

📊 效率统计 & 导出

  • 点击 效率统计 查看完成数、平均耗时、中位耗时等
  • 统计只认手动 partial → done 事件耗时，0 分钟不计入
  • 导出分析包 输出 JSON 数据，适合 AI 分析或论文引用
  • 🕊️ 推送进度 一键推送当前进度到企微群

🎯 大禹 ID 导入

  • 使用油猴脚本在大禹平台抓取关卡数据，导出 JSON 文件
  • 点击 🎯 导入大禹ID，自动按名称匹配关卡并填入 dayuId

⌨️ 快捷操作

  • Ctrl+V — 全局粘贴截图识别
  • Ctrl+Enter — 备忘输入框快速提交
  • 点击服务状态灯 — 重新检测本地服务连接
💡 本工具需要配合本地 Python 服务运行（端口 18765）。服务在线时，状态灯显示绿色，支持文件夹创建、资产扫描等功能。
