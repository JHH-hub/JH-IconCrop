# JH-IconCrop

✂️ **图标裁剪工具** - 批量裁剪和处理图标

基于 Web 界面的图标裁剪工具，支持批量处理。

## 🚀 使用方法

### 方式一：直接运行
双击 `icon裁剪工具.html` 在浏览器中使用。

### 方式二：打包版
运行 `build.bat` 打包成独立 exe。

## 📁 项目结构

```
JH-IconCrop/
├── icon裁剪工具.html   # 主界面
├── launcher.py        # Python 启动器
├── build.bat          # 打包脚本
└── 裁剪.ico           # 应用图标
```
