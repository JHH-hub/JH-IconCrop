# JH-IconCrop

✂️ **Icon 裁切工具** — 在一张大图（精灵图 / 茬点合集）上批量框选、裁剪、命名并导出图标。

纯单文件 HTML 实现，离线可用；同时支持打包成独立 Windows exe。

## ✨ 功能特性

- **可视化框选**：拖拽框选裁剪区域，支持 `Shift` 强制正方形、`Ctrl + 滚轮` 缩放、适应窗口。
- **鼠标拖动 / 缩放**：选中选区后可直接拖动整体移动，或拖动 8 个角点/边手柄调整大小。
- **精准微调**：选中选区后用方向键移动（`Shift` 加速），`Alt + 方向键` 调整大小，`Tab` 切换选区。
- **撤销栈**：`Ctrl+Z`（或画布右键）可回退增删、移动、缩放、正方形化、清空等任意操作（最多 50 步）。
- **手动坐标**：可直接输入 X/Y/宽/高 精确添加选区。
- **正方形化**：一键将所有选区以中心点扩展/收缩为正方形。
- **批量命名**（需公司内网）：
  - 🤖 **AI 解析**：粘贴茬点列表文本，自动提取图标名字。
  - 📷 **截图识别**：粘贴 / 选择截图，OCR 识别图标名字。
  - ✨ **智能匹配**：用视觉模型识别选区缩略图，自动匹配候选名字。
  - 名字 chip 可拖拽到任意选区上命名。
- **导出**：
  - 📦 批量裁剪后打包为 ZIP（PNG / WebP / JPEG，可统一缩放到目标尺寸）。
  - 🖼️ 导出带编号 / 名称标注的整图，便于核对。
  - 内置清晰度 / 透明背景风险检测（JPEG 会丢失透明通道并提示）。
  - 文件名自动去重，重名追加序号。

## 🚀 使用方法

### 方式一：直接运行
双击 `icon裁剪工具.html` 在浏览器中使用，无需安装。

### 方式二：打包版
运行 `build.bat` 用 PyInstaller 打包成独立 `dist\Icon裁剪工具.exe`（单文件、内嵌 HTML、带图标）。
打包脚本直接使用版本受控的 `Icon裁剪工具.spec`，保证配置唯一、可复现。

> 注：打包版 exe 的运行方式是「释放内嵌 HTML 到临时目录 → 调用系统默认浏览器打开」，
> 导出的 ZIP / 标注图会通过浏览器下载到默认下载目录（非 pywebview 另存为对话框）。

## 🔐 关于 Venus Token（AI 功能）

AI 解析 / OCR / 智能匹配依赖公司内网 Venus LLM 代理，需要 Token。

- Token **不再硬编码进源码**，首次使用 AI 功能时会弹窗提示输入。
- Token 仅保存在**本机浏览器 localStorage**，不会上传、也不会提交到仓库。
- 可随时点右侧面板「⚙ 配置 Token」按钮修改。

## ⌨️ 快捷键

| 操作 | 快捷键 |
|------|--------|
| 强制正方形框选 | `Shift` + 拖拽 |
| 拖动选区 / 缩放选区 | 选中后拖动选区主体 / 拖动 8 个手柄 |
| 移动选区 1px / 10px | `←↑↓→` / `Shift` + 方向键 |
| 调整选区大小 | `Alt` + 方向键 |
| 切换选区 | `Tab` / `Shift+Tab` |
| 撤销 | `Ctrl+Z` / 画布右键 |
| 取消激活 / 清空选区 | `Esc`（一次取消激活，再次清空） |
| 缩放画布 | `Ctrl` + 滚轮 / `+` / `-` |

